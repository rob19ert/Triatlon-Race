# Roadmap: пошаговый план и требования

Источник — `TZ_multisport_Roblox.md` + решения ниже. Делаем строго по шагам: шаг закрыт, когда пройден его **тест**. После каждого шага — коммит, push, Cmd+S в Studio.

## Принятые решения (13.11.2026)

| Вопрос | Решение | Отличие от ТЗ |
| --- | --- | --- |
| Стиль | **Пати-хаос**: кнопка толчка, мельницы/маятники, зрелищные падения | ТЗ: аркадный спорт, толчка нет |
| Визуал | **Мультяшный** (скруглённые формы, яркие эффекты) | — |
| Рубеж на стрельбище | **Свой по стартовому номеру**, если занят — ближайший свободный | ТЗ: ближайший свободный |
| Возврат после падения (бег) | **Мгновенно** на начало препятствия | ТЗ: задержка 1 с |
| Падение с велосипеда | **Мгновенно назад на ту же ветку**, ближайшая точка позади, без штрафа | ТЗ предлагал +3 с |
| Боксы | **Только на себя** | — |
| Толчок | **Только кулдаун**, без цены по пульсу; не работает на стрельбище; на финишной прямой — можно (14.11.2026) | — |
| Мало игроков | **Старт с 1 игрока** по таймеру лобби; призраки — Фаза 4 | ТЗ: добивать призраками до 4 |
| Сервера | **Одна карта на сервер, гонки по кругу**; хаб + телепорт — Фаза 3 | — |
| Мобильное управление | **Тач-кнопки сразу в MVP** | — |

Все числа ниже — стартовые, живут в `Config`.

## Фаза 1. MVP — бег и стрельба

Уже сделано (задачи 1–8 из CLAUDE.md): RaceManager, полоса препятствий с чекпоинтами, пульс и красная зона, два стрельбища (лёжа/стоя), ветер, качание, задержка дыхания, штрафные петли со счётчиком над головой, лента итогов стрельбы, масс-старт, таблица позиций, точность в итогах.

### 1.1 Фикс рубежей  ✅
- Свой рубеж по стартовому номеру, запасной — ближайший свободный.
- Мишени рубежа сбрасываются, когда его занимает новый стрелок.
- Предупреждение в логе о дублях `Index` / рубежах в одной точке.
- На каждом стрельбище **12 рубежей** (под максимум игроков). ✅ (шаг 7 стадов, щиты 6,8)
- Стрельбище стоя построено заново (`Range2`, мишени 0,72) со своей петлёй `PenaltyLoop2`; трасса удлинена, финиш на z≈−520. `PenaltyService` поддерживает несколько петель (атрибут `Order`). ✅ проверено соло-плейтестом: лёжа → петля 1 → стоя → петля 2 → финиш.
- Лобби ждёт загрузки персонажа (раньше при медленной загрузке таймер перезапускался). ✅
- **Тест:** 3 клиента, приходят вместе и по очереди → у каждого свой рубеж, мишени открыты. ✅ (13.11.2026, стрельбище лёжа)

### 1.2 Лобби с 1 игрока  ✅
- `Race.MinPlayers = 1`: гонка стартует по таймеру лобби с любым числом игроков; при 12 — сразу.
- Догонялка отключена при < 3 участников (уже есть `CatchUpMinRacers`).
- **Тест:** опубликованный сервер с одним игроком — гонка стартует через 30 с. ✅ (13.11.2026, проверено в браузере)

### 1.3 Кнопка толчка  ✅
- Клавиша **F** / тач-кнопка «Толчок». Сервер толкает ближайшего соперника в конусе впереди, радиус ~6 стад, импульс в сторону от толкающего + чуть вверх.
- Кулдаун 5 с (сервер проверяет). Пульс не тратит.
- Запрещено: на рубеже (и толкать игрока, который там). На финишной прямой — можно (14.11.2026).
- Доработка 14.11.2026: радиус 8, конус ±100° (вперёд и вбок), сила 45/18, соперник падает на 0,6 с, кулдаун 3 с, неуязвимость цели 1,5 с, анимация рук (Transform суставов, поддержка AnimationConstraint).
- HUD: иконка кулдауна.
- **Тест:** 2 клиента — толчок сдвигает соперника; повтор раньше 5 с игнорируется сервером; в запретных зонах не работает. ✅ (13.11.2026, 2 клиента; сила снижена до 32/14)

### 1.4 Хаос на препятствиях  ✅
- **Маятники**: качающийся груз поперёк дорожки, сбивает и отбрасывает.
- **Мельницы**: вращающиеся лопасти, выталкивают с балки/платформы.
- Сбивание = короткий **ragdoll ~1 с**, потом встаёт; упал с трассы — мгновенный возврат на чекпоинт.
- Движение препятствий — на сервере (детерминированно по времени), чтобы у всех одинаково.
- **Тест:** маятник сносит игрока, мельница сталкивает в воду → возврат; на 3 клиентах препятствия синхронны. ✅ (13.11.2026, 3 клиента)
- **Итог:** 3 маятника (после брёвен, после стенки, над средней балкой). Мельница убрана с трассы — непроходима; код поддержки (тег `Windmill`) остался.

### 1.5 Фотофиниш и подиум  ✅
- Финиш фиксируется по точному времени пересечения (интерполяция между кадрами). Разница < 0,1 с → в ленте «Фотофиниш!» и замедленный повтор не обязателен — достаточно отметки в таблице.
- После гонки топ-3 ставятся на подиум, камера всех игроков смотрит на подиум 5 с, затем таблица результатов.
- Таблица: место, время, точность (9/10), (боксы — с Фазы 2).
- **Тест:** 3 клиента финишируют → подиум с правильной тройкой, таблица верна. ✅ (13.11.2026, 3 клиента)
- **Итог:** время финиша интерполируется по плоскости FinishLine; подиум `Track/Podium` (Spot1–3, Camera); итоги 5 с подиум + 10 с таблица. Для тестов: в Studio DNF через 5 мин, клавиша **G** — к финишной линии (только Studio).

### 1.6 Режим зрителя  ✅
- Финишировавший (и DNF) переходит в зрителя: камера следует за другим гонщиком, переключение ← / → (тач-стрелки), подпись имени и позиции.
- По умолчанию — за лидером среди ещё бегущих.
- **Тест:** 2 клиента, один финишировал — видит второго, переключение работает. ✅ (13.11.2026, 3 клиента)

### 1.7 Тач-управление  ✅
- Экранные кнопки: Спринт (есть), Прыжок (стандартный), Толчок, на рубеже — Выстрел и Дыхание, прицел — свайпом.
- Кнопки не перекрывают HUD пульса и таблицу на экране телефона.
- **Тест:** Studio Device Emulator (телефон) — гонка проходится целиком без клавиатуры. ✅ (13.11.2026)
- **Итог:** модуль `TouchButtons` — кнопки дугой вокруг прыжка, видны по последнему вводу (касание — да, клавиатура/мышь — нет); на рубеже Спринт/Толчок заменяются на Огонь/Дыхание с откатом.

### 1.8 Мультяшный визуал MVP-карты  ✅
Тема — **летний спорт-парк**, плотность декора средняя. Сезоны переключаемые (решено 13.11.2026):
детали окружения несут атрибут `Role` (Grass, Path, Water, Foliage…), палитры ролей по сезонам — в `Config.Themes`,
сезонный декор — в папках `Decor/<Сезон>`, небо/свет — из палитры; применяет `ThemeService` при старте сервера.
- **1.8a** Каркас сезонов + летний мир: ThemeService, палитра «Лето», трава вместо серого пола, холмы и лес по краям, пруд, перекраска трассы.
- **1.8b** Стадион: трибуны (старт, стрельбища, финиш), щиты с выдуманными брендами, будка комментатора на вышке, операторский кран и камеры.
- **1.8c** Живые болельщики (подпрыгивают, когда рядом игрок / финиш; анимация на клиенте) + табло позиций и фотофиниша (SurfaceGui).
- **1.8d** Эффекты и звуки: конфетти при попадании, пыль при падении, салют на финише; выстрел, «дзынь», стук сердца, свисток.
  - **Итог (13.11.2026):** частицы оставлены (конфетти, пыль, салют); из звуков — только удар маятника. Выстрел, попадание, сердце, свисток, трибуны убраны — не понравились, подобрать позже (`Config.Sounds`).
- Цель: 60 FPS на среднем телефоне (эмулятор + MicroProfiler).
- **Тест:** визуальный прогон после каждой части, нет просадок FPS.
- **Позже (отдельный шаг):** палитры «Зима» и «Горный курорт», ротация/голосование сезона в лобби.

### 1.9 Плейтест с друзьями (3–5 человек)  ✅
- Публикация в приватный доступ, запись: время гонки, точность, жалобы.
- **Критерий:** хотят ли сыграть ещё раз без просьбы. По итогам — правка баланса в `Config`.
- **Итог (13.11.2026):** бег — понравился. Стрельба «хромает»: идея нравится, но не хватает динамики;
  главная жалоба — **нет ощущения выстрела**. → шаг 1.10.

### 1.10 Стрельба 2.0 (по итогам плейтеста)
Порядок — от главной боли («нет ощущения выстрела») к самому большому изменению.
- **1.10a Отклик выстрела** ✅ (13.11.2026): отдача камеры, мишень эффектно падает/закрывается шторкой, серии «2 подряд!» / «🔥 3 подряд!» / «ЧИСТО 5/5!».
  Звуки выстрела и попадания — только после выбора пользователем на слух (присылаю кандидатов со ссылками).
- **1.10b Давление соперников** ✅ (14.11.2026): над соседними рубежами — сколько закрыл каждый (●●●○○); время на рубеже; табло и болельщики реагируют на чистую стрельбу.
  - Доработка: плашка стрельбы «как в трансляции» (`ShootingBroadcast`) — справа под таблицей, видна всем: секции по стрельбищам, ●/промах/пусто, ник, штраф, аватар; заменила панель «Соседи».
- **1.10c Награда за риск** ✅ (14.11.2026): 5/5 → турбо +20% на 6 с (надпись, FOV, огненный шлейф у всех); золотая мишень (40%, на 40% меньше) → −3 с, штраф может уйти в минус, везде показывается со знаком. Числа — `Config.Reward`.
- **Доработки 14.11.2026:** мгновенный отклик выстрела — клиент предсказывает попадание по общей формуле (`Aim.findHit`), сервер подтверждает/исправляет; шторка быстрее (0,08 с). В итогах (табло подиума, протокол) и у финишировавших — только итоговое время со штрафом.
- ~~**1.10d Ритм-дыхание**~~ → заменено: **мушка-маятник** ✅ (13.11.2026). Игрок не целится, мушка сама ходит через все мишени, задача — нажать вовремя. Скорость — по пульсу на входе, дрожь — по текущему; дыхание замедляет. **Ветер убран** — и так достаточно сложно.
- **Тест:** после каждой части — плейтест на 2+ клиентах; в конце — повторный плейтест с друзьями: «стрельба ощущается?».

### 1.11 Штрафное время вместо штрафных кругов (по итогам плейтеста)  ✅
- Каждый промах сразу +3 с к индивидуальному времени (`Config.Penalty.SecondsPerMiss`), над игроком всплывает «+3 с» — видят все.
- Итоговое время = время до финишной линии + штраф; места, подиум и фотофиниш — по нему. Таймер, таблица позиций, табло, зритель и итоги показывают штраф.
- Штрафные петли (`PenaltyLoop`, `PenaltyLoop2`) удалены из мира, проёмы в левом ограждении закрыты.
- **Тест:** 2 промаха → «+3 с» ×2, таймер «(+6 с)», итоговое время = время + 6 с.
- Промах на рубеже: над прицелом красное «+3 с» вместо «мимо».
- **Усталость на экране** (`FatigueFx`, `Config.Fatigue`): с пульса 70 камера «дышит», края экрана темнеют и пульсируют в такт; в красной зоне — красная виньетка, размытие, выцветание. Звук дыхания — ждёт выбора пользователя на слух.
- ✅ (13.11.2026)

## Фаза 2. Велосипед

### Решения по карте (14.11.2026)
- **Схема «стадион + петля»** (как в биатлоне): стадион остаётся хабом. После стрельбы лёжа — поворот влево
  через проём между трибунами в **велопарк** (посадка), петля по парку на запад, возврат в велопарк (высадка),
  стрельба стоя, финиш. Прямой проход между стрельбищами закрывается.
- **Пересмотр 14.11.2026:** петля была скучной и длинной → **круг ~1 мин (~2300 стад)**, озеро и деревня убраны,
  больше событий. Состав: **Холм** (туннель насквозь / через вершину с ускорителем) → вираж → **Трамплин-парк**
  (ускорители, 2 трамплина с ямами, кочки, маятник, бревно-вертушка) → вираж → **Лес** (змейка с виражами / прямо
  через 2 оврага с трамплинами + маятник) → **Возврат** (кочки, вертушка, ускоритель) → велопарк.
- **Съезд с дороги:** на земле дальше 3 стад от края — мгновенно на центр дороги в ближайшей точке, лицом по ходу
  (не к чекпоинту). Ямы под разрывами — зона падения → чекпоинт перед трамплином.
- **Трамплины бросают сами** (зона LaunchPad), ускорители +30% на 2 с. Числа — `Config.Bike`.
- На велосипеде можно доехать до рубежа «стоя» (высадка у входа на стрельбище) — в 2.1.
- **Пересмотр 2 (14.11.2026):** круг ещё меньше — **~35–40 с (~1400 стад)**, овал рядом со стадионом.
  Сначала обычный круг, потом делим его на зоны и насыщаем «приколами». Дорога — плитки с текстурой грунтовки
  (`rbxassetid://219255691`) веером по 7,5° на поворотах, как у моделей «Поворот дороги» Nikitosik_385; плитки
  травяные (роль Ground) — края текстуры сливаются с газоном.

### 2.0 Серый макет петли
- Велопарк в проёме между трибунами (посадка — северная половина, высадка — южная, между ними разделитель),
  прямой проход по дорожке между стрельбищами закрыт.
- Петля из простых блоков: дорога, развилки 4 участков, подъёмы/спуски (клинья), вода/овраги (FallZone), без отделки.
  Декор (деревья, холмы), попавший на петлю, — убрать/сдвинуть.
- Только Studio: команда «режим велосипеда» (скорость 40) — проехать петлю до появления велосипеда.
- **Тест:** петля проходится от посадки до высадки по каждой ветке; время ~2 мин на шоссе; ветки сходятся.

### 2.1 Аркадная модель велосипеда
- Не физика колёс: персонаж с повышенной скоростью и прикреплённой моделью велосипеда. Посадка в зоне после первой стрельбы, высадка перед финальной.
- Пульс: езда держит ~50, педали-спринт +8/с, спуск без педалей −5/с.
- За пределами трассы (трава, песок) −40% скорости.
- **Тест:** проезд по прямой, повороты, подъём/спуск, пульс меняется по правилам.

### 2.2 Драфтинг
- 1–4 м позади соперника 2 с → +8% скорости и медленнее рост пульса; индикатор на HUD.
- **Тест:** 2 клиента — эффект включается и выключается корректно.

### 2.3 Трасса с развилками
- 3 участка, на каждом 2–3 ветки (шоссе / горная −15% / экстрим −30%), сходятся в конце участка. Таблички за ~5 с до развилки.
- Невидимые зоны проверки в каждой ветке; пропустил — этап не засчитан.
- Падение в обрыв → мгновенно на ближайшую точку той же ветки позади.
- Позиции в таблице считаются по пройденной дистанции с учётом ветки.
- **Тест:** проезд каждой ветки; срезка по полю не засчитывается; таблица корректна на разных ветках.

### 2.4 Секретные боксы
- `MysteryBoxService`: эффекты только на себя, шансы из ТЗ (лидеры / отстающие). Бокс исчезает на 10 с только для взявшего.
- Пати-хаос: эффекты зрелищные (визуал, звук), числа — в Config для балансировки.
- **Тест:** серия из 200 симулированных взятий даёт распределение ≈ таблице; каждый эффект проверен вручную.

### 2.5 Плейтест
- **Критерий:** боксы не решают исход слишком часто.
